# K7 Sonic Cyber Ultimate Mix Gravation

An original cassette-tape music project.

This repository is the public home for the project identity, future masters, tape-session notes, and the signal chain behind each recording.

## Archive

- `masters/` - Final mixes and reference versions
- `tape-notes/` - Session dates, deck setup, signal chain, and production notes
